# Operating Model

## Agent independence

Planning and final audit should be performed by different agent roles where
the host supports subagents. This reduces confirmation bias.

## Evidence first

An objective can move to complete only when its acceptance evidence exists.

## Human authority

The user remains the authority for:
- destructive actions
- production actions
- credentials
- permissions
- ambiguous high-impact decisions

## Failure transparency

Failures are categorized and recorded. The system never hides failed attempts
or converts them into a success claim.
